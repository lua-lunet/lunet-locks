## Judgement calls (disclosed)

1. **Failover definition.** "Failover" everywhere = the runner's
   `failover_ms`: cycle-begin anchor → first client operation served on
   the abdicated node's connection (`tools/lib/polite2.tl:569`). The verb
   drive is a separate figure (8/8/7, 11/6/9 ms). The tex states this
   definition rather than leaving "failover" undefined.
2. **Takeover definition.** `takeover_ms` = TERM-begin (or cut-begin)
   anchor → first client operation served — the same client-visible rule
   as failover, which is what makes the contrast apples-to-apples. SB7's
   R2 figure (≈6.5 s, 2 s window granularity, bounded [4.5, 6.5] s) is a
   different measurement rule on a different run and is deliberately NOT
   used in the contrast; only the two probe-measured 20,318/20,370 ms
   figures are.
3. **ReincarnationRefused 9/9.** The spec summary says "9/9
   ReincarnationRefused"; the data say all 9/9 crash-rejoins fence, with
   `ReincarnationRefused` refused at every kill boot (1,155 refusals) but
   the *newest* diagnostic at the fenced node varying
   (ReincarnationRefused ×4, EvidenceNotCollected ×2, ViewMismatch ×1 in
   SB8's family table; P2's three all GapDetected). The tex states the
   accurate version: refusal at the pre-kill view is the universal
   mechanism, the newest named diagnostic varies, the outcome (fenced,
   depth-independent) does not.
4. **Plane rate.** The spec headline "651–652 dg/s" is exact for the two
   n2-led steady windows (S1 651.6, S4 652.0); the n1-led window S3 is
   641.0/s. The tex states 641.0–652.0 with the per-window figures rather
   than flattening to 651–652.
5. **Ratio span.** "677–923×" pairs each run's takeover against its own
   abdication cycles (P2: 20370/30=679 … 20370/26=784; SB8:
   20318/30=677 … 20318/22=923). The naive cross-run max (20370/22=925.9)
   is not used; the span quoted bounds what the same-run data support.
6. **`\ref{sec:demo}` unresolved** in the standalone file by design — it
   binds to the host paper's demonstration section when the body is
   pasted into `results_20260915.tex` (two deliberate `??`-binding
   points, lines 52 and 78).
7. **Figures.** No figure files were created or copied: each figure
   environment carries the real source SVG path and a conversion command
   in its leading comment; the `\includegraphics` names follow the host
   paper's `diagrams/*.png` convention (`rsvg-convert` if present,
   `qlmanage -t -s 1800` as the macOS fallback producing PNG).
8. **polite2 flight-record total.** Deliberately omitted: the per-kind
   counts in P2's report cover four kinds per node, not the full kind
   set, so a summed total would overstate precision. The two record
   totals quoted (791,409 wire / 783,988 flight) are the exact ones from
   SB7 and SB8.
